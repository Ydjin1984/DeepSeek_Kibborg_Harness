# @deepseek-ai/dsh-client-ui-settings-skills

[English](README.md) | 中文

**Skills** 设置分区——Skills Manager 页签。浏览器插件注册一个本地化的 `settings.section` 贡献，id 为 `skills`；设置外壳拥有导航条目。所有技能状态都由宿主侧的 [`skill-manager`](../../skill/skill-manager/README.md) 服务持有，并通过共享 wire 客户端的 `skills` 与 `llm` 域传输，因此本包不持有任何自己的持久数据——它在分区挂载时读取快照，并在每次自身变更后重新读取。

分区把受管目录分成两组列出——**My skills**（文件系统范围：user、project、agents）与 **Built-in**——并在名称、描述、用途以及本分区已读过全文的技能正文上做实时过滤。每张卡片显示名称、描述、范围、路径、状态、调用策略、版本、来源与最近一次基准评测结果，并提供 Enable/Disable、View、Edit、Versions、Benchmark 与 Delete 操作。内置技能只读：不渲染 Edit 或 Delete 操作。目录下方的回收站分区可恢复或永久删除已回收技能。分区在它所轮询的基准评测落定后重新读取目录，因此状态徽标反映的是新近持久化的摘要，而非挂载时的快照。

**Create skill** 把 `/skill-create` 复制到剪贴板，并引导用户去聊天界面，由系统技能的向导编写新技能文件。编辑器运行管理器要求的保存管线——先 validate、再 security-check、最后 save——并在对话框内解决被阻断的安全裁决（仍保存）与同名冲突（替换既有）。版本对话框可把技能回滚到任意已存版本。基准评测对话框从 `llm.models` 选择任务与评测模型，运行宿主基准评测，轮询到完成，并渲染质量分数、提升百分比、token/时间/工具调用增量与逐用例行，运行中可取消。目录上方的工具栏提供同样的任务/评测/用例数选择与 **Run all benchmarks** 操作：它通过 `skill.benchmarkBatchStart` 为每个受管（非内置）技能启动一个顺序宿主基准评测，批量运行期间锁定控件、提供批量取消、以当前技能显示进度行，并在所有运行落定后按裁决汇总结果。工具栏选择会预填每个技能的对话框运行表单。

## 数据流

分区的操作在 `apply` 中基于共享 `connection.api` 一次性构建，并通过其 inject face 交给组件，因此组件从不直接触碰 wire 客户端或任何服务。分区把目录快照、搜索词、展开状态与对话框载荷保存在本地状态——这些是读取手势，不是共享事实——每次变更都走注入的操作并重新读取目录。活动语言标签挂在 inject hooks 舱中，因此日期与数字格式跟随 UI 语言，而组件无需订阅 locale 服务。

## Model Experience

None，as 本包只渲染浏览器管理 UI，自身从不组装或发送 provider 请求；基准评测任务由宿主的 `skill-manager` 服务执行，该服务记录自身的模型影响。

#### KV Cache 影响

None；本包既不组装也不发送 provider 请求。

## 已知限制与延后工作

- **内容搜索只覆盖已读过的正文** —— 目录快照携带摘要，因此全文搜索匹配每个技能的名称、描述与用途，外加本分区已加载过详情（经 View/Edit/Versions）的技能内容。新挂载的分区不会预读每段正文。
- **同一时间只有一个基准评测对话框** —— 在另一张卡片上打开 Benchmark 会丢弃前一个对话框的运行视图；若运行落定前对话框被关闭，宿主运行本身继续，其结果会落在卡片的下一次目录刷新上（保持打开直到落定的对话框会自动刷新目录）。
- **分区级快照** —— 切换页签保留当前快照，重新打开 Settings 会获得新快照；没有对 skill-manager 变更的推送订阅。
